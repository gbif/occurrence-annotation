# gbifrules_get

gbifrules_get

## Usage

``` r
gbifrules_get(url, query, user = NULL, pwd = NULL)
```

## Arguments

- url:

  helper

- query:

  helper

- user:

  optional user for authentication, defaults to GBIF_USER env variable

- pwd:

  optional password for authentication, defaults to GBIF_PWD env
  variable
